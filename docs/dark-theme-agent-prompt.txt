Sin esos cambios, Ops no puede guardar `layout_key: "dark"`. El template
resuelve `dark` cuando el API ya envía esa clave; claves desconocidas
siguen cayendo a `default`. No simular que el flujo Ops→sitio ya funciona.


Contexto
--------

Monorepo Real State. Trabaja SOLO en:

  real_state_site_template/  (Next.js App Router, puerto dev 3002)

1 deploy = 1 inmobiliaria (ACCOUNT_ID + API_URL). Marca, layout, idiomas y dominio
vienen de SiteConfig via GET /api/public/site_config?account_id=.

Objetivo: cuando Ops guarde layout_key: "dark", el template renderiza el theme
dark en / y /inmueble/[slug].


Arquitectura (no romper)
------------------------

  src/app/page.tsx -> resolveSiteThemeFromConfig() -> theme.Catalog
  src/app/inmueble/[slug]/page.tsx -> theme.ListingDetail

Contrato: src/themes/theme-types.ts (CatalogThemeProps, ListingDetailThemeProps).

Reglas:
  - Server Components; sin fetch de listings dentro del theme.
  - i18n: getSiteUi(lang) / getDarkUi(lang) + site-i18n.ts.
  - Marca: getResolvedSiteConfig / getPublicSiteContent.
  - Theme = skin: Inquiry, WhatsApp, specs y href salen de ListingInquiryForm,
    ListingWhatsAppButton, publicListingCardModel, listingPublicSpecsLocalized.
    NO copiar esos flujos en src/themes/dark/.


Alcance v1 — theme Dark
-----------------------

Referencia visual: HTML midnight/rust/gold (no portar su JS, Unsplash, DEO/Tijuana
ni inquiry simulada). Tarjeta según imagen overlay. Secciones según capturas.

Catálogo: header, hero cinematográfico, buscador con “Limpiar filtros”,
resultados (`total` del API), filtros Link, paginación, ubicaciones configuradas
(sin recuentos), about (#nosotros), proceso, opiniones o principios, contacto,
CTA final si hay canal, footer.

Ficha: paridad funcional con default (galería, specs, inquiry, WhatsApp, maps,
share, descripción completa).

Datos:
  listings representa: la página actual del catálogo (limit/offset).
  total representa: meta.total del API (inventario filtrado, no de la página).
  locations representa: solo SiteConfig / content.locations (nunca el lote
    paginado). Sin locationCounts.
  locationCounts: no aplica.

styledLayout en componentes compartidos: true


Cableado obligatorio (template)
-------------------------------

  2. theme-registry.ts       — Catalog, ListingDetail, LegalPage, ListingLoadError

NO modificar app/page.tsx, app/inmueble/[slug]/page.tsx ni rutas legales.
NO usar site-config.ts legacy. NO fetch al Rails desde el browser.
NO remapea default / luxury / deo / beige / elegant / orange / ultra.
