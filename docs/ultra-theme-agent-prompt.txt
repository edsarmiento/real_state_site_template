Sin esos cambios, Ops no puede guardar `layout_key: "ultra"`. El template
resuelve `ultra` cuando el API ya envía esa clave; claves desconocidas
siguen cayendo a `default`. No simular que el flujo Ops→sitio ya funciona.


Contexto
--------

Monorepo Real State. Trabaja SOLO en:

  real_state_site_template/  (Next.js App Router, puerto dev 3002)

1 deploy = 1 inmobiliaria (ACCOUNT_ID + API_URL). Marca, layout, idiomas y dominio
vienen de SiteConfig via GET /api/public/site_config?account_id=.

Objetivo: cuando Ops guarde layout_key: "ultra", el template renderiza el theme
ultra en / y /inmueble/[slug].


Arquitectura (no romper)
------------------------

  src/app/page.tsx -> resolveSiteThemeFromConfig() -> theme.Catalog
  src/app/inmueble/[slug]/page.tsx -> theme.ListingDetail

Contrato: src/themes/theme-types.ts (CatalogThemeProps, ListingDetailThemeProps).

Reglas:
  - Server Components; sin fetch de listings dentro del theme.
  - i18n: getSiteUi(lang) + site-i18n.ts.
  - Marca: getSiteUi().config (SiteConfig via getResolvedSiteConfig).
  - Theme = skin: Inquiry, WhatsApp, specs y href salen de ListingInquiryForm,
    ListingWhatsAppButton, publicListingCardModel, listingPublicSpecsLocalized.
    NO copiar esos flujos en src/themes/ultra/.


Alcance v1 — theme Ultra
------------------------

Referencia visual: HTML editorial vino (no portar su JS, datos de ejemplo,
Unsplash, DEO/Tijuana ni inquiry simulada).

Catálogo: header, hero (caption por encima de miniaturas), buscador compartido,
resultados con contador real, ubicaciones, about, proceso, contacto, CTA final,
footer, acceso admin.

Ficha escritorio: título a todo el ancho; ubicación + compartir; columnas ~7/12
(galería, miniaturas, descripción) y ~5/12 (precio, specs, inquiry/WhatsApp,
ubicación). Móvil: una columna, sin recortes.

styledLayout en componentes compartidos: true


Cableado obligatorio (template)
-------------------------------

  1. theme-definitions.ts    — { name: "ultra", layoutKeys: ["ultra"] }
  2. theme-registry.ts       — Catalog, ListingDetail, LegalPage, ListingLoadError

NO modificar app/page.tsx, app/inmueble/[slug]/page.tsx ni rutas legales.
NO usar site-config.ts legacy. NO fetch al Rails desde el browser.
NO remapea default / luxury / deo / beige.


i18n (desde Ops)
----------------

getSiteUi(lang); selector ES|EN si show_locale_switcher; localizedHref().


Admin / login
-------------

isStyledSiteLayout(): layout_key !== "default" -> acentos de marca en admin/login.


Fuera de alcance
----------------

Nuevos campos SiteConfig, cambios en API/Ops, deploy Vercel.
